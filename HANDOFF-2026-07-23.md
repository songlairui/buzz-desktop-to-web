# Buzz Web Adaptation — Handoff 2026-07-23

## 项目背景

将 Buzz Desktop (Tauri) 的前端改造为可在浏览器运行的 Web 版本，部署在 `https://chat.f.mtt.cool`。
Web 版通过 Nginx 反代连接运行在 Fedora 宿主机上的 `agent-daemon-server.js`（端口 3001），从而访问 Nostr relay、ACP 运行时、host 侧 40+ 自定义模型等资源。

2. **`list_managed_agents` mock 不完整**（缺 `agent_args` 等 RawManagedAgent 字段）  
   → `AgentInstanceEditDialog` 挂载时 `agent.agentArgs.join` 崩  
   → 修复：补全 snake_case RawManagedAgent mock + mapper/`join` 防御

3. **`get_agent_memory` 未实现** → 返回 `[]`/`{}`  
   → `memoryQuery.data.memories.length` 崩  
   → 修复：shim 返回 `{ core: null, memories: [], ... }` + Panel 守卫

4. **危险回退**：daemon 对未知 cmd 返回 **HTTP 200 + `{}`**，shim 当成功  
   → 修复：空对象不采纳；更多 list 类 cmd 显式 stub `[]`

5. **模型下拉用的是 `discover_agent_models`**，不是 `get_agent_models`  
   → 修复：shim 把 `discover_agent_models` 映射到 daemon 的 `get_agent_models`

### buzz://connect on web
Browsers **cannot** register `buzz://` custom protocol for https origins.
Equivalents now work:

| Entry | Example |
|-------|---------|
| Path | `https://chat.f.mtt.cool/connect?relay=wss://buzz.f.mtt.cool` |
| Query | `https://chat.f.mtt.cool/?connect=wss://buzz.f.mtt.cool` |
| Paste URI | `https://chat.f.mtt.cool/?uri=buzz://connect?relay=wss%3A%2F%2Fbuzz.f.mtt.cool` |
| Manual form | Welcome → Join / existing member → paste `buzz://connect?relay=…` or `wss://…` |

Implementation: `desktop/src/shared/api/shims/web-deep-links.ts` + pending-queue IPC + `inviteHelpers`/`relayProbe` parse of `buzz://connect`.
